Key differentiator

Trust is the product: measured accuracy and self-healing agents

The reason government AI pilots stall is not building — it is trusting. Wakeel makes quality measurable and repairable by the business owner, not a data scientist.

The Feedback loop (live in the prototype)

  • Auto-generated test suites — AI reads the agent's steps and writes realistic cases, including Arabic inputs and privacy edge cases
  • Employee feedback #1 — edit or replace any generated case; add your own
  • AI judge — every run scored pass/fail with a reason; accuracy ring per agent
  • Employee feedback #2 — written rules the agent must obey ("always end with a bilingual signature")
  • Self-healing — failures + feedback are sent back to the AI, which revises the agent and re-tests automatically

Measured on the live prototype

8 sfull test run incl. AI-judge verdict
11 sself-heal cycle: revise agent + save
18 s6 auto-generated test cases
“Was 67% accurate — self-healed to 100% on 9 July.” The audit trail every entity can show its leadership.

Security & sovereignty

Built for government constraints, not adapted to them

Data residency

  • Per-entity deployment in Azure UAE North, sovereign clouds (G42 / Moro / Khazna) or on-premises
  • Azure OpenAI UAE region keeps prompts and citizen data in-country
  • Option for fully local models where classification requires it

Isolation & control

  • One instance per entity — no shared tenancy, clean accreditation boundary
  • Entities bring their own model API keys; switch providers in Settings without re-architecture
  • Exportable agent packages — no vendor lock-in

Accountability

  • Per-user activity log: who built, tested, healed, published — with timestamps
  • Accuracy evidence per agent before go-live (test suites & scores)
  • Roadmap: UAE Pass / Entra ID SSO, role-based approvals inbox

Licensing posture (validated against the Dify open-source license)

Commercial use as a backend is expressly permitted. Per-entity single-workspace deployments avoid the multi-tenant clause entirely; one branding remedy (or an enterprise white-label license from LangGenius) clears the console-branding clause. Full compliance brief available as a separate document.
